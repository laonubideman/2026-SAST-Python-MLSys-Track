# 五分钟演示与随机追问

## 30 秒开场

> 这不是一个调用现成框架的 MNIST Demo。我从原始二进制数据解析开始，用 NumPy 实现 Softmax 回归和两层 ReLU 网络，手写交叉熵、反向传播和小批量 SGD。之后将同一训练算法翻译为 C++ 循环和 CUDA kernel，通过 pybind11 接入统一的 Python 评估入口，再用数值梯度和后端参数差验证正确性。

## 五分钟演示顺序

1. **结果**：打开 README 的收敛曲线、混淆矩阵和错分样本。
2. **结构**：讲数据、模型、后端和评估如何解耦。
3. **算法**：只写一条核心公式 `X.T @ (P - one_hot(y)) / B`。
4. **跨后端**：说明 NumPy、C++、CUDA 执行同一轮参数更新。
5. **反直觉结果**：朴素 C++ 比 NumPy 慢，分析 BLAS、SIMD 和缓存层次。
6. **边界**：不虚构 CUDA 实测，主动给出下一步优化路线。

## 高频追问

### 1. 为什么 Softmax 先减最大值？

防止 `exp` 溢出。分子和分母同时乘 \(e^{-c}\) 不改变概率，但最大指数变成 1。

### 2. 为什么真值类别所在位置要减 1？

交叉熵对 logits 的梯度是 \(P-Y_{one-hot}\)。原数组已经是 \(P\)，真值位置减 1 就在原地构造了这个梯度。

### 3. `X.T @ probabilities` 的形状是什么？

`X.T` 是 \(D\times B\)，`probabilities` 是 \(B\times K\)，结果是 \(D\times K\)，正好与 `theta` 同形状。

### 4. 为什么两层网络不能全零初始化？

多个隐藏神经元如果初始状态相同，就会收到相同梯度，一直学成相同特征。随机初始化用于打破对称性。

### 5. 为什么要先算完 `W1_gradient` 和 `W2_gradient` 再更新？

`W1_gradient` 的链式求导需要旧 `W2`。提前更新 `W2` 会将两个不同参数状态混在同一次反向传播中。

### 6. Epoch、batch 和 SGD 分别是什么？

Batch 是一次用来估计梯度的样本集合；SGD 用该梯度更新一次参数；epoch 表示所有训练数据被遍历一次。

### 7. 为什么 C++ 比 NumPy 慢？

NumPy 调用高度优化的底层矩阵库。朴素 C++ 循环缺少 SIMD、分块、多线程和微架构调优。编程语言更底层不代表实现一定更快。

### 8. pybind11 起什么作用？

它将 NumPy 的 C 连续内存暴露为 C++ 指针，检查形状后调用原生函数。`theta` 通过指针原地修改，不需要构造新参数数组。

### 9. CUDA 中一个线程负责什么？

第一个 kernel 一个线程负责一个样本的十个类别；第二个 kernel 一个线程负责一个 `theta[feature, class]` 参数。

### 10. 如何证明三个后端计算正确？

先用有限差分验证 NumPy 分析梯度，再使用相同初始参数和数据比较 C++/CUDA 与 NumPy 更新后的最大参数差。

### 11. 项目有什么不足？

两层网络没有偏置项，C++ 未进行分块或并行化，CUDA 未使用共享内存/cuBLAS，且 Apple Silicon 上无法完成 NVIDIA GPU 性能实测。
